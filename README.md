# Once de Barrio

Juego de fútbol para armar un equipo, jugar un Mundial y competir en un ranking.

## Integrantes

Santino De Lucca, Santino Aiello, Candela Reinoso y Mía Maldonado.

## Tecnologías

Vue, JavaScript, HTML, CSS, PHP, MySQL y Node.js con WebSockets.

## Cómo abrirlo

1. Instalar XAMPP en `C:\xampp` y Node.js.
2. En la carpeta del proyecto, ejecutar `npm ci`.
3. Iniciar Apache y MySQL desde XAMPP.
4. En una base nueva, importar primero `once_de_barrio.sql` y después `migracion_sistema.sql` desde phpMyAdmin. Hacerlo una sola vez.
5. Abrir `Abrir sistema conectado.cmd`.
